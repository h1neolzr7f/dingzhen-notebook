# 用户指南

## 1. 导入截图

在粉笔官方客户端打开本人已完成的试卷，把题目页和解析页截图复制到一个目录。运行桌面端后选择批量导入；系统会按文件名和显式序号排序，并用哈希去重。失败截图不会删除。

每道题必须分别标注 `question` 和 `analysis` 页面。OCR 只是候选结果，确认页面中的用户答案、粉笔正确答案和粉笔官方解析后再保存。

## 2. 校对与状态

`VERIFIED` 表示必需字段和证据齐全；`NEEDS_REVIEW` 表示仍需人工处理。常见原因包括缺粉笔答案/解析、低 OCR 置信度、答案冲突、题号失败和解析页截断。校对只修改结构化候选，不覆盖原始截图。

## 3. ADB 采集

用户在手机上打开本人有权查看的已完成试卷，启用 USB 调试并授权电脑，再从 CLI/GUI 连接设备。采集器保存原始 PNG、设备序列号、屏幕尺寸/密度和帧哈希；页面连续不变达到阈值或遇到异常时安全停止。详见 `docs/p2-adb-capture.md`。

## 4. Android 采集伴侣

安装 APK 后依次完成悬浮窗权限、屏幕录制授权；自动模式还需手动开启无障碍服务。选择手动、半自动或自动模式；自动模式只有在三项必需内容和解析末尾齐全时才前进，遇到登录、弹窗、网络或页面停滞会暂停。每张 PNG 都会在手机私有目录落盘并记录检查点，可稍后用 USB 或带一次性共享密钥的安全 LAN 传输到电脑。详见 `docs/p4-android-capture.md`。

## 5. 分析与组卷

导入并校对后，调用 `packages.analysis` 获取总题数、正确率、知识点和错误标签。使用 `packages.paper_builder` 生成空白错题卷、答题卡、答案与解析册、风险卷、专项卷或重复错误卷。空白卷不会显示答案；答案与解析册只使用粉笔官方字段。

## 6. AI 与复习

AI 分析是可选的。先确保题目为 `VERIFIED`，再使用 `AIAnalysisService` 生成单题错误因子、整卷总结、历史趋势、学习策略和复习计划。AI 输出存放在 `ai_analysis`，不会写入官方答案/解析；重复输入从缓存返回。

## 7. 数据和隐私

默认数据在 `data/`，导出在 `exports/`。不要把真实截图、账号信息或密钥提交到版本库。项目仅面向个人、合法可见的学习内容，不绕过登录、付费或平台风控。

## 8. 安装、模型与故障日志

Windows 用户解压分发 ZIP 后运行 `FenbiStudy-Installer.exe`。安装器先校验 `FenbiStudy.zip`，再安装并创建快捷方式。真实 OCR 首次使用会下载官方模型；完成一次初始化后可以离线识别。程序若发生未捕获异常，会把堆栈追加到 `%LOCALAPPDATA%\FenbiStudy\logs\crash.log`，不会保存密码、Cookie 或 Token。
